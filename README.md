# PYchat 🤖

Un chatbot IA local utilisant un système de chaîne de Markov. Entièrement développé en HTML pour bloc-notes et 100% fait maison !

## 📋 Caractéristiques

- **IA Légère** : Conçue pour fonctionner sur des machines peu puissantes
- **Chaînes de Markov Améliorées** : Moteur linguistique trigram V4 optimisé
- **Multi-plateforme** : Compatible Windows 7, 8, 8.1, 10, 11+ (32 et 64 bits)
- **Système de Vectorisation** : Amélioration de la compréhension contextuelle
- **Méthode de Similarité Jaccard V3** : Matching question/réponse avancé
- **100% HTML** : Exécutable dans n'importe quel navigateur

## 🚀 Installation

1. Téléchargez le fichier `PYchat3.0.2.html`
2. Ouvrez-le avec votre navigateur web préféré
3. C'est tout ! Le chatbot est prêt à l'emploi
