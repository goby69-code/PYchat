# PYchat 3.5

PYchat est un assistant IA local entièrement conçu en HTML, CSS et JavaScript pour fonctionner directement dans votre navigateur. Il fonctionne sans serveur, sans compte et sans envoi de données externes.

La version actuelle est la 3.5, avec une interface moderne, un moteur de réponse hybride et des outils avancés pour le chat local.

## Fonctionnalités

- IA locale 100 % côté client
- Moteur de réponse hybride : question/réponse + chaîne de Markov + réseau neuronal interne PYNet
- Interface de type chatbot moderne, inspirée des assistants web
- Historique de conversations avec recherche et gestion
- Nouveaux chats, renommage, suppression et reprise de discussions
- Mode vocal avec reconnaissance vocale et synthèse vocale
- Thèmes clair / sombre / système
- Import et export de conversations (JSON / Markdown)
- Gestion des paramètres avancés et laboratoire d'expérimentation PYNet
- Compatible avec les navigateurs modernes sur Windows, macOS et Linux
- Aucune dépendance externe requise

## Installation

1. Téléchargez le fichier `PYchat3.0.5.html`
2. Ouvrez-le dans votre navigateur web
3. Commencez à discuter immédiatement

Aucune installation, aucune commande à lancer, aucun backend à configurer.

## Utilisation

- Écrivez votre message dans la zone de discussion
- PYchat répond automatiquement selon le moteur actif
- Vous pouvez modifier les paramètres dans le menu des réglages
- Le mode vocal permet de parler et d’écouter les réponses
- Le laboratoire PYNet permet d’expérimenter le réseau interne et ses performances

## Paramètres utiles

La version 3.5 inclut plusieurs options avancées :

- seuil de bascule entre moteurs
- longueur des réponses Markov
- ordre de la chaîne de Markov
- activation de suggestions fantômes
- activation de PYNet et réglage du seuil de confiance
- support optionnel d’un modèle local Ollama
- configuration du thème et de la taille du texte

## Notes de conception

PYchat est conçu pour être léger, autonome et facile à utiliser sur des machines modestes. Il privilégie l’exécution locale, la simplicité d’usage et l’expérimentation sans dépendre d’un service cloud.
