# PYchat

PYchat est un chatbot local en français, conçu comme un projet léger et expérimental. Le dépôt décrit une application web autonome utilisant notamment des chaînes de Markov.

## Version et fichiers disponibles

- `PYchat3.8.0.html` : application HTML actuellement présente dans le dépôt (version 3.8.0).
- `PYchat-3.9.2.exe` : fichier annoncé comme version 3.9.2, mais il ne contient actuellement que 2 octets. Il ne s’agit pas d’un exécutable utilisable en l’état.

La version 3.9.2 ne peut donc pas être considérée comme publiée tant qu’un véritable binaire n’a pas été ajouté. En attendant, utilisez le fichier HTML 3.8.0.

## Démarrage

1. Téléchargez `PYchat3.8.0.html` depuis le dépôt.
2. Ouvrez le fichier avec un navigateur moderne.
3. L’application web se lance localement, sans installation d’un serveur.

## Fonctionnement

Le projet est présenté comme un chatbot local fondé sur un système de chaîne de Markov. Consultez le code HTML pour connaître précisément les fonctionnalités et les dépendances de la version fournie.

## Confidentialité

L’application HTML peut être ouverte localement. Vérifiez le comportement du code et les paramètres de votre navigateur avant d’y saisir des informations sensibles ; les fonctionnalités ou intégrations réseau éventuelles dépendent de la version utilisée.
