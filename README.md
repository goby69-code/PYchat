# PYchat

Un chatbot IA local utilisant un système de chaîne de Markov. Entièrement en HTML pour bloc-notes et 100% fait maison.

## Caractéristiques

- **IA légère** : Conçue pour les machines peu puissantes
- **Chaînes de Markov** : Moteur trigram V4 optimisé
- **Multi-plateforme** : Compatible Windows 7 à 11+ (32 et 64 bits)
- **Vectorisation contextuelle** : Amélioration de la compréhension
- **Similarité Jaccard V3** : Matching question/réponse
- **100% HTML** : Exécutable dans n'importe quel navigateur

## Installation

1. Téléchargez `PYchat.html`
2. Ouvrez-le avec votre navigateur
3. C'est tout !

## Utilisation

Lancez le fichier HTML et commencez à converser. L'IA améliore ses réponses au fil du temps.
